# Version 1.1: first-use clarity

The recovery rules, five-minute wall deadline and twelve fixed future checks
are unchanged. This release gives edit receipts the same names as the controls,
explains results before technical identifiers, and separates resumable progress
files from evidence exports.

**Save progress to a file** preserves the original deadline. It cannot renew an
attempt or undo accepted history. **Export and inspect evidence** contains the
attempt JSON, verification packet, HTML report and read-only inspection.

The new default is a genuine setup with three necessary configuration changes.
Its five actual calls replay unchanged before the separately authored fault.
The earlier inspect/advance recording and test fixture remain in the gallery.
[Recording evidence](MODEL_RECORDING.md) gives exact actions and limits.

Both fixed initial profiles retain their actual state through replay and save
restoration. A completed construction includes settings, clock alignment, scene
version, revision, event history and pending work. The checker never resets a
candidate before scoring it.

See [BUILD_REPORT.md](../BUILD_REPORT.md) for checks actually completed for the
shipped source. Automated desktop, phone and keyboard checks cannot establish
human comprehension. The updated human exercise remains empty, research is
disabled, and this local package has not been deployed or published.
